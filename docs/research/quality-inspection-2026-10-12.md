## 2. 威胁模型与证据可信度

链路为买家 → 平台 Edge/sub2api → 卖家出口代理（HTTP CONNECT/SOCKS5）→ 官方固定 base_url。前提是证书校验开启、不信任卖家 CA、卖家不能修改 Host/base_url；代理只转发端到端 TLS 字节流。【一手：真伪报告 §1、sub2api HTTP 客户端源码】

| 风险 | 本期判断 | 证据与处置 |
|---|---|---|
| 卖家改正文、注入安装命令、伪造官方服务 | 在上述链路前提下不能由出口代理实现 | 不对每个卖家运行供应链/注入探针；平台配置与网关自检列后续 |
| 订阅档位/模型权限虚报 | 可能 | A01 声明展示、A04 型号请求、A05 上下文边界；不能从利用率猜档位 |
| 账号被外部共用、窗口提前消耗 | 可能，外部消耗因果不能只凭失败率确认 | D04/D05/D13 先用生产证据；窗口起点、并发承载、刷新令牌复用等列后续 |
| 官方降低 effort、改路由或按信任度回退 | 有论文/源码报告，但不能宣称本平台账号普遍发生 | D06/A09/D07/A02/A12 配对核验，先排除官方允许回退和平台改写 |
| 上下文不足、静默截断、完整输出不足 | 可通过受控题验证 | A05/D09/D08；明确计数、结束原因与通道能力 |
| 代理连接质量或平台自身容量问题 | 可影响延迟与可用性 | D10/D13、platform 错误分类；先归因，不当成智力错误 |

“多人共用或走代理导致降智”是风险假设，不是已证明的普遍因果。基线同期也下降时应调查官方事件；不能因为新模板比旧饱和题难，就把 7 天历史下降全归为官方。

身份证据按下列顺序使用：现有原始上游型号记录 → 同入口、同请求输入计数 → 经 A/A 校准的确定参数行为 → 能力配对 → 第三方结论。模型自报身份、文字风格、id 前缀、thinking 文本长度均不作认证依据。Claude Code/Codex/Antigravity 系统提示会污染自报；网关可能把 model 改回请求名，Antigravity 也可能生成 Claude 风格 id。

A02 先归一化日期别名、规范 ID 与官方 GLM/Kimi/Gemini/Grok 自动路由白名单，不能直接处罚 `upstream_model_mismatch=true`。A03 Claude 总输入计数包含 input/cache_creation/cache_read，OpenAI cached_tokens 是 input 子集；不同入口与动态多轮输入不能直接要求相等。当前网关不能取得的 `OpenAI-Model`/Claude 核档/原始 modelVersion 不伪造证据。当前 HEAD 增加 beta 白名单、缓存 TTL 顺序修正、Codex 搜索历史补齐与统一协议路由，详见网关对照，契约标签仍为 v0.2.14。

## 3. 本期质检项目录

编号沿用真伪调研，**编号不是全部启用的承诺**。配置项决定 SKU/基准，成色项决定 Q，门槛先于 Q；同一证据只扣一次。不适用、未测、无法判定分别记录，均不扣价、不授予认证。

### 3.1 配置与真伪

| 项 | 本期测法 | 判定与影响 |
|---|---|---|
| A01 订阅档位 | 授权令牌中可读的声明；Claude 缺字段标未核验 | 展示与选择 appraisal_base；官方核档后续，不扣成色 |
| A04 型号权限 | 每个上架型号发一次短请求 | 主型号无权限：上架不通过；其他型号逐项标注 |
| A05 上下文上限 | 略超下一低档边界的输入；记录被接受长度和真实 input_tokens | 宣称 1M 实为 256K、复现静默截断为门槛；仅通过 128K 不认证 1M |
| A06 推理档位 | 显式 effort，记录接受/拒绝与推理量响应 | 实测标注；接受但量不变转 D06，不把网关归一后的同档当多个档位 |
| A11 功能 | thinking、工具 auto、图片/PDF、Schema、多轮；虚拟本地工具 | 基线也不支持为不适用；实际缺失按功能项，系数须校准，不额外重复扣 |
| A02 响应型号一致 | 生产记录与探针原始 model，归一化/路由白名单 | 偶发提示；持续不一致复核后重扣；只作为第三方确认身份门槛的辅助证据，不独立新增门槛 |
| A03 计数指纹 | 同入口同期、有效输入相同的逐请求计数比对 | 首次提示；两次以上复现先排除网关配置后作为重扣证据 |
| A15 参数规则指纹 | 型号级确定的参数边界，与两个基线 A/A | 仅提示；校准后启用，网关本地 400 不作厂商指纹 |
| A12 回退与拒答 | HTTP 200 refusal、实际作答 model 与无害对照 | 真实内容触发/白名单回退不罚；无害对照持续回退复核后重扣 |
| 第三方身份 | 沿用 BazaarLink 提交/轮询/脱敏结论 | 明确身份不符为身份门槛；家族匹配不认证具体子型号，模糊/不足不扣 |

A02/A03/A12 的“重扣”需要关联到已确认的能力缺失与组内系数，不能凭未知异常另乘一个真假系数。方案未给出这些重扣的完整数值/归组映射，正式扣价前须运营校准登记；第三方明确确认身份不符按门槛处理。自报伪装单条不能替代归一化与复核。

### 3.2 成色、性能与可用性

| 项 | 证据与统计 | 起步影响/限制 |
|---|---|---|
| D06 推理强度兑现 | 10–20 道 high 锚，完整加 low；配对推理 token 的对数比、置信区间与档位响应度 | ratio<0.6 且 CI 上界<0.8：0.70；否则确认 ratio<0.8：0.85；无证据不扣，待校准 |
| A09/D07 智力配对 | 参数化题同实例配对 McNemar；SPRT 使用同一配对与剔除规则 | 显著较低分档 0.85/0.70；严重下降由 SPRT 触发 degraded 门槛；relative_score 仅保留展示 |
| D09 上下文深度 | 8K/32K/128K 多针、多跳、聚合、首尾、联想针 | 不足重扣；具体档位阈值待校准；计数确认的静默截断为门槛 |
| D08 输出完整性 | 长枚举/代码改写的完整结果、占位符与 stop_reason | 0.95；Codex OAuth 删除 max_output_tokens，不出此类题；截断不同时扣智力 |
| D12 缓存功能 | 每账号自身同长前缀两步，与基线自身两步比较 cache read | 0.85；CloudFront Miss 不能证明模型缓存，单次无命中不足以扣 |
| A08 知识代际 | 同期基线的截止附近安全事实题，不写死时事金标 | 只提示，不是推理强度指标 |
| D13 可用率 | 7 天 usage_records + edge_attempts；先关联请求/账号，失败与成功去重，不能只取成功用量作分母 | ≥99.5%：1；99–99.5%：0.97；98–99%：0.93；95–98%：0.85；90–95%：0.75；24h<90% 经样本复核为 unavailable 门槛 |
| D04 异常 429 | 窗口未耗尽仍频繁 429，排平台容量与正常窗口耗尽 | 2–10%：0.95；>10%：0.85；来源不清不扣 |
| D10 速度 | 7 天同模型/入口/输入长度档同行 TTFT P50 与 TPS；同行≥4，否则同期基线配对 | 1/0.97/0.93/0.85 四档；TTFT≤同行 P25 且 TPS≥P75，且双方有效时奖励1.05 |
| D05 余量/隐私 | 现有用量快照与可支持的隐私设置 | 只展示；不可检测厂商标未知 |

D13 排除平台侧错误、买家请求错误与正常额度窗口 429；无生产流量时使用合格探针，并标明来源。主动探针 429/529 单独退避、不算探针可用失败；生产异常 429 由 D04 独立评价，不能因此同时作为“答错”。7 天不足 90%但24小时已恢复时仍提示历史风险，最低成功率系数暂为0.75；不能仅凭一次失败触发24h门槛。样本下限与小样本处理待运营校准。

D10 候选分界（来自定价调研 §3.4）：TTFT≤同行P50 为1，P50–P75 为0.97，>P75 为0.93，>2×P50 优先取0.85；TPS≥同行P50 为1，P25–P50 为0.97，<P25 为0.93，<0.5×P50 优先取0.85。配对回退阈值不能直接借用同行分位数，须另校准。双优奖励先检查，再取性能组系数1.05；仅单指标优不奖励。

## 4. 质量系数、等级与价格

```text
门槛先判断：确认门槛 → degraded / unavailable，上架不通过，不计算新 Q 与估价
能力 = min(推理强度, 智力, 上下文深度, 输出完整性)
功能 = max(0.7, thinking × 工具 × 图片/PDF × 缓存)
可用 = max(0.6, 成功率 × 异常429)
性能 = min(TTFT系数, TPS系数)，范围[0.85,1.05]；双指标优时统一给1.05
Q = clamp(能力 × 功能 × 可用 × 性能, 0.5, 1.05)
```

JSON Schema/多轮是 A11 功能的验证面，不增一个方案外乘法因子；同根因合并到对应功能项。不适用/无法判定作为中性1参与已有有效组，但明确报告覆盖不足；完全没有有效观测时 Q=null，排序回退1，不展示为满血。不得用 min(所有项) 取代功能/可用组的乘法及下限。

等级原始分档：S 为 Q≥1.02 且连续30天无门槛、7天可用率≥99.5%；A 为[0.93,1.02)，B 为[0.82,0.93)，C 为[0.65,0.82)，D 为<0.65。Q≥1.02但S历史不足时最高A，不伪造30天历史。带±0.02滞回：已处边界上方降级需低于边界−0.02，已处下方升级需达到边界+0.02；首次无等级按原分档。S 升级需Q≥1.04及全部历史条件，S降级候选条件为Q<1.00，或S历史资格失效时最高A；非门槛资格失效同样连续两次有效确认，不能因分数仍高而永久保留S。非门槛降级连续两次有效确认，未测/不确定/反向结果打断连续计数；门槛即时映射健康处置，不等待等级两次。

| 价格/调度对象 | 规则 |
|---|---|
| 寄售估价 | `appraisal_base(厂商,tier，default兜底) × Q`，读时计算；独立于 buyback_base，改基准即时生效；缺配置显示未配置 |
| 卖家寄售价 | 仍只校验厂商 consignment_min/max，任何等级均不新增质检限价；显示高于/低于估价的百分比，分母为空/零则不显示 |
| 买家指定卖家价 | 仍为 m_s × (1+c)，估价是卖家侧倍率，比较时必须同口径 |
| 回收价 | QuoteFor：buyback_base × GradeCoefficients，再按最严格启用默认池 PoolCap 封顶、round4；等级正式模式由Q决定 |
| 回收默认系数 | 保留S1.2/A1/B0.85/C0.7/D0；只建议管理员校准后手动考虑S约1.1，不改迁移/代码默认 |
| 默认保障池 | formal且独立调度开关开启时，Plan 默认分组循环加等级≥默认B、无门槛；原毛利/健康约束仍成立 |
| 寄售排序 | quality_adjusted 的 ConsignmentPriority 按m_s/Q每0.05分桶；回收1–19、寄售50–79段不变；未测Q取1 |
| 专属分组 | 不受新增保障池最低等级限制，仍受旧健康状态/挂单状态限制 |

inspection.mode 默认试运行：新项/Q/估价只展示，grade、回收与调度按旧判定；正式才使新题接入降智与Q定级。调度 enabled 默认false，关闭时规划器对相同输入的输出必须与现状一致，包括成员、优先级、并发和参数；正式定级/门槛产生的grade/health输入变化仍按现有规划器处理；suspected 的旧并发减半等不改。等级变化通过报告“对你的影响”告知，开放扣价项申诉，不新建通知服务。回收报价到期后降低需卖家确认、确认前暂停的现状保留。

数字是[智力调研 §1–3、§8](inspection/intelligence-items.md)引用的公开来源报告，不是已验证的本平台题库难度。8 类 Go 生成器为斑马、骑士无赖、寄存器、AIME式数学、代码输出、字符串日期、中英约束、长上下文；研究13模板保留作候选，53例不直接全部上线。工具语义、多轮、完整输出、中文大写金额、事实弃权用少量静态/半参数化题。

## 6. 报告、预算、校准与阶段验收
